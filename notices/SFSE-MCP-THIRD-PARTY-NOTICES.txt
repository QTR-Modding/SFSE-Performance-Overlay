SKSE-MCP
--------

SFSE-MCP directly adapts SKSE-MCP's public header at the exact revision below,
including its resolver pattern, section-key convention, high-level facade,
generated ImGuiMCP types, and GetProcAddress forwarding bodies. In addition to
the necessary SKSE-to-SFSE namespace, module, path, include, and package
substitutions, this port corrects misspelled public type/export names, initializes
and makes registration owners non-copyable, and adds failure/null checks.
`AddWindowWithView` remains source-compatible; the Starfield host creates a
normal framework window and currently ignores its view name because the pinned
Skyrim host never implemented the referenced export.

The later host ABI names and signatures for runtime rename/delete and
API-version queries were checked against SKSE Menu Framework 3
`resources/SKSEMenuFramework.h` at commit
c8cfc5c93fa3b5f6261cef695ab814e4467dd980 (GPL-3.0-only):
https://github.com/QTR-Modding/SKSE-Menu-Framework-3/blob/c8cfc5c93fa3b5f6261cef695ab814e4467dd980/resources/SKSEMenuFramework.h

The full-path helper reuses the original `AddSectionItem` ABI. All four
SFSE-MCP resolver wrappers are independently written in the existing MIT
interoperability pattern and contain no menu-tree, parser, or other GPL host
implementation.
